## How we work
- Every task is one pull request (PR), and the PR title starts with the Task ID (example: S1-DEV-02).
- Every PR needs 1 teammate review before it is merged.
- Nobody pushes straight to `main`.
- Never upload passwords, .env files, or personal data.
- Task plan and status are tracked in our team's Google Sheet.
